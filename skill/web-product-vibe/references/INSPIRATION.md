# Method Inspiration

This skill is an original synthesis inspired by public patterns from several projects. It does not copy their workflow text or templates.

## BMad Method

Useful ideas adopted conceptually:

- progressive context from idea/research → product → UX → architecture → build
- product brief and customer-first pressure testing before implementation
- explicit implementation-readiness gate
- focused story/slice execution instead of one giant build

Source: https://github.com/bmad-code-org/BMAD-METHOD

## GitHub Spec Kit

Useful ideas adopted conceptually:

- separate WHAT from HOW
- specification before implementation
- explicit task decomposition

Source: https://github.com/github/spec-kit

## OpenSpec

Useful ideas adopted conceptually:

- written agreement on scope before coding
- explicit handling of requirement change rather than silent drift

Source: https://github.com/Fission-AI/OpenSpec

## AI Coding Project Boilerplate

Useful ideas adopted conceptually:

- UI specification as a first-class artifact
- acceptance/E2E emphasis
- requirement convergence before implementation

Source: https://github.com/shinpr/ai-coding-project-boilerplate

## WDS / UX-oriented BMad extensions

Useful ideas adopted conceptually:

- user scenario and interaction behavior before developer implementation
- product/UX thinking as a separate discipline from architecture

The implementation in this skill is intentionally smaller and optimized for a non-programmer using AI coding agents.

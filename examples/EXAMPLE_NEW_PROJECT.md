# 示例：从模糊想法开始

用户：

> /web-product-vibe 我想做一个给跨境电商新手用的 AI 商品研究 Web 工具。先 DISCOVER，不写代码。GitHub 找同类项目，优先最近维护和有真实 UI 的，帮我取长补短。

Skill 应先：

1. 明确用户和核心任务
2. 调研不同类型参考项目
3. 分别提取产品、用户旅程、UX/UI、技术与代价
4. 只形成候选方案，不直接堆功能
5. 产出产品 Brief 和待验证假设

接着用户：

> 进入 DESIGN。先从一个第一次使用的新手角度把完整旅程、页面、每个页面状态和下一步设计清楚。

再：

> 进入 PLAN。冻结 MVP，明确不做什么，再倒推最小技术方案和纵向开发 Slice。

最后逐 Slice BUILD + ACCEPT。

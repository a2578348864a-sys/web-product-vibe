# DeepSeek Harness

Canonical source in this repository:

```text
skill/web-product-vibe/
```

Project-level installation target:

```text
<project>/.agents/skills/web-product-vibe/
```

Codex and DeepSeek Harness can therefore use the same installed project-level skill directory.

Example:

```text
Use web-product-vibe. Enter BUILD. Implement only the current vertical slice, then run ACCEPT.
```

Do not maintain a separate DeepSeek-specific copy of the core workflow unless a real host incompatibility requires it.
